# 首次使用：把真实主数据录进来

面向「刚把系统装好、库还是空的」那种状态。按下面的顺序录，每一步都依赖前一步的数据。

> 先确认你在哪个环境：**生产** `https://localhost:8453/mfg`（真实数据），
> **开发** `https://localhost:8443/mfg`（测试数据，随便折腾）。
> 首次登录都是 `admin` / `ofbiz`，**生产环境会强制你先改密码**：登录后页面只有一张
> 「请先修改默认密码」的表单（当前密码填 `ofbiz`，新密码至少 5 位），改完才进得去。
> 开发环境为了跑巡检脚本，这个门禁是关的（系统属性 `org.langhua.mfg.requirePasswordChange=N`）。
> 忘了新密码：停实例后 `gradle loadAdminUserLogin -PuserLoginId=admin` 重置回 `ofbiz`。

## 1. 录入顺序

| # | 做什么 | 在哪个页面 | 依赖 |
| --- | --- | --- | --- |
| 1 | 建型号 | 产品与 BOM `/mfg/control/products` | — |
| 2 | 导 BOM | 同上，型号页面里的 BOM 导入框 | 型号 |
| 3 | 配工序（可选） | 同上，工艺路线表单 | 型号 |
| 4 | 建库位（可选） | 库位 `/mfg/control/locations` | — |
| 5 | 到货批次 | 物料批次 `/mfg/control/materials` | 料号（不需要先建型号，料号是自由文本） |
| 6 | 来料检验 | 物料批次页的检验表单 | 批次 |
| 7 | 安全库存（可选） | 库存 `/mfg/control/stock` | 料号 |
| 8 | 外协厂家（可选） | 外协厂家 `/mfg/control/vendors` | — |
| 9 | 客户 / 买家名单（可选） | 销售订单 / 买家名单 | — |

### 1.1 型号

产品与 BOM 页顶部「新建 / 更新型号」：

- **型号编码**：`BT5-PRO` 这种。**最长 10 个字符**——SN 前缀默认取它，而 SN 前缀字段只有 10 位；
  编码更长时，要么在「SN 前缀」里填一个短的，要么保存会直接报错。
- **标准工时/台**：先填估计值就行，跑几批真实生产后可以用学习曲线回填覆盖（型号页会注明来源）。
- **工时费率**：元/小时，成本核算用。
- **保修月数 / 售价**：售后和毛利要用。
- 保存后页面下半部分就是该型号的成本块、BOM、工序、照片。

### 1.2 BOM

同一个型号页面里的 BOM 导入框，把表格粘进文本框（模板见 [`templates/bom-template.csv`](templates/bom-template.csv)，
用 VSCode / 记事本打开，直接双击用 Excel 打开中文可能乱码）：

```
料号,名称,用量,位号,关键件,单价
R0402-10K,10K 电阻 0402,4,R1-R4,N,0.05
```

- **Tab 分隔也行**：直接从 Excel 选一区域复制粘贴就能用（逗号与 Tab 都认）；带逗号的内容用双引号包起来。
- Excel 另存的「CSV UTF-8」带 BOM，导入时会自动忽略，不会把 `\ufeff` 吃进料号。
- 以 `#` 开头的行是注释。**表头那行必须写成 `#料号,名称,...`**，否则会被当成一个料号导入。
- 用量留空按 1，关键件留空按 `N`。
- **单价别空着**：空的能存，但成本页会黄条提示「缺单价」，单台成本偏低却看不出来。
- 同一个型号再次导入时，不勾「追加」会先清空当前 BOM 版本的行（导入前想清楚）。

### 1.3 工序（可选）

有工序模板时，成本按工序分摊（`工序工时 × 费率`），比一个总数更准。每行填：工序号、工序名、工作中心、标准工时/台。
报工时如果出现模板里没有的工序号，成本页会单列成「工艺外工序」，工时不会丢。

### 1.4 库位（可选）

货架编码 + 类型（仓库 / 区域 / 货架）+ 上级库位。到货和移库时可以指定库位；没指定的算「未分配库位」。
预留只做到批次层，不按库位拆。

### 1.5 到货批次

物料批次页的 CSV 导入框（模板见 [`templates/lot-template.csv`](templates/lot-template.csv)）：

```
料号,名称,供应商,供应商批号,数量,到货日期
R0402-10K,10K 电阻 0402,立创商城,DC2410A,5000,2026-10-20
```

- 料号统一转大写；数量必须 > 0，否则这行被跳过；日期留空按今天。
- 新批次默认**待检**（`MFG_IQC_PENDING`），待检和让步接收都能发料，**只有判不合格（FAIL）才挡发料**。
- 批次号自动生成 `LOT-yyMMdd-NN`（同一天超过 99 个会变 3 位）。
- 到货就写一条 RECEIPT 流水，库存页/流水页立刻能看到。

### 1.6 安全库存（可选）

库存页给每个料号设阈值与补货量；低于阈值会在库存页标红并进看板告警，欠料清单也能直接导 CSV 给采购。

## 2. 销售订单的行怎么写

销售订单页的「行明细」是一个文本框，一行一个型号：

```
BT5-PRO,20,2026-11-30
BT5-LITE,10
```

- 格式 `型号,数量[,交期]`；交期可空。
- 保存后系统**先锁定库里已有的成品**，不够的留在欠货里，详情页点「排产」自动开工单（已有工单就加量）。

## 3. 第一笔真实数据的验收路径

按这个顺序走一遍，等于把整条链路验收一次：

1. 建型号 → 导 BOM → 配工序 → **看成本块**是否等于你手工算的单台成本
2. 到货 → 来料检验（试一次判不合格，确认发料被拒）
3. 开销售订单（先锁在库）→ 不够就排产
4. 开工单 → 看齐套欠料是否 0（料够的话）→ 报工 → 完工入库（生成成品批次 `FG-<工单号>`）
5. 出货单（只收完工的 SN）→ 在 SN 页看整台履历
6. 报表页看良率 / 单台工时 → 点「喂进学习曲线」→ 估算 → 「回填到型号标准工时」→ 回型号页确认来源与成本变化
7. 看板 / 告警 / 质量指标：口径是不是你要的

> 学习曲线要有意义至少需要 **3 个批次**（迭代剔除最少保留 3 个点），跑 5 批以上更稳。

## 4. 常见坑

| 现象 | 原因 |
| --- | --- |
| 型号保存报「SN 前缀最长 10 个字符」 | 型号编码超过 10 位且没填 SN 前缀 |
| 导入后多了一个奇怪的料号 | 表头行没写 `#` |
| 导入数量是 0 | 数量列空或 ≤ 0，这行被跳过 |
| 成本偏低、黄条提示 | BOM 行没填单价 |
| 发料被拒「Only X left in lot」 | 该批次可发量不够（含已被其它工单预留的部分） |
| 完工了但出不了货 | SN 还是 `MFG_IN_PROGRESS`：先在工单页点「完工入库」 |
| 学习曲线没法回填 | 估算口径是「成本」，只有「工时」口径能回填标准工时 |

## 5. 出问题怎么反馈

一条一个问题，带上这四样就够复现：**哪个页面 → 我期望什么 → 现在是什么样 → 单号（工单/批次/订单）**。

> 注意：`mfg-it.bat`、`verify-*.ps1` 这些脚本会**写测试数据**，只能对开发实例（8443）跑，别对生产实例跑。
